## インストール

```powershell
scoop install oh-my-posh
New-Item -Path $PROFILE -Type File -Force
notepad $PROFILE
```

ファイルに下記の内容を記述する。

```powershell
$themePath = "https://raw.githubusercontent.com/JanDeDobbeleer/oh-my-posh/refs/heads/main/themes/spaceship.omp.json"

oh-my-posh init pwsh --config $themePath | Invoke-Expression
```

シェルを再起動する。

## フォント

引数なしでinstallを実行するとリストが表示されるので、インストールしたいフォントを選択してインストールする。
```powershell
oh-my-posh font install 
```

インストールが完了したらWindow Terminalの外観設定でフォントを設定する。
