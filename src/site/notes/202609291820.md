|Class|Subclass|主な役割・特徴|試合前に絞る選択|
|---|---|---|---|
|**Tank**|—|耐久・CCで戦闘をコントロール|**Engage / Disengage**|
||Vanguard|自分から戦闘を開始する|Engage寄り|
||Warden|味方を守り、敵の仕掛けを拒否する|Disengage寄り|
|**Fighter**|—|火力と耐久を両立して近接戦をする|**Damage / Durability**|
||Juggernaut|高火力・高耐久、低機動力|**Damage / Durability**|
||Diver|敵陣へ入り重要対象へ到達する|**Kill / Setup**|
|**Slayer**|—|高い機動力と火力で敵を倒す|―|
||Assassin|脆い重要対象へアクセスして脅威を与える|**先入り / 後入り**|
||Skirmisher|継続火力・機動力・条件付き生存力で近接戦をする|**Front-to-back / Dive**|
|**Mage**|—|スキルを中心にダメージ・CCを提供|―|
||Burst|短時間に火力を集中させて対象を落とす|**Setup / Follow-up**|
||Battlemage|中近距離で継続的に戦闘へ影響する|**Damage / Utility** ※仮|
||Artillery|長射程から安全にPokeする|**Burst / DPS**|
|**Marksman**|—|AAを中心に継続的な物理ダメージを出す|**Crit / On-hit**|
|**Controller**|—|味方の支援と敵の行動制御|―|
||Catcher|CCで敵を捕まえる・味方を守る|**Catch / Peel**|
||Enchanter|Heal・Shield・Buffなどで味方を強化|**Primary Targetを決める**|
