Open in New tabとかいう神プラグインを使うと実現可能。
https://community.obsidian.md/plugins/sfb-open-in-new-tab

エディタのハイライトはCSSスニペットで追加
```css
.markdown-source-view.mod-cm6:not(.is-live-preview) .cm-line.cm-active {
    background-color: rgba(128, 128, 128, 0.15) !important;
}
```

編集画面と表示が分離されるだけでずいぶん使いやすくなるもんだなと関心する。
Markdownエディタは編集画面とプレビュー画面は分離すべきだ。
