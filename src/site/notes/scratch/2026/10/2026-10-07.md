## hermes agent

一旦はSOUL.mdだけ設定してしばらく使ってみることにする。

## AgentとのSamba共有

画像などのアセットをAgentと共有したいのでSambaサーバへの接続経路を作ることにした。

状態確認

```bash
# OS
(
  . /etc/os-release
  printf 'OS: %s\n' "$PRETTY_NAME"
)

# Sambaのバージョン
smbd --version

# サーバーの役割と認証方式
sudo testparm -s --parameter-name='server role'
sudo testparm -s --parameter-name='security'

# 同名のユーザー・グループがすでに存在するか
getent passwd lulu
getent group lulu
```

なんとすでにユーザが存在した。過去の自分も同じことをやっていたのだろう。

## hermesにGithubアカウントを割り当て

bot用のGithubアカウントはすでに作成済みなので、その権限を使ってGithubにアクセスできるように設定をする。Botに直接PATを渡すのではなく、うまいこと権限を管理する方法がないか調査してから取り掛かることにする。
