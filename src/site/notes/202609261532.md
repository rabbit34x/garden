Microsoftに努めているような優秀なエンジニアでも、理解するまで何度も何度も繰り返し理解に務めている。

初動の早さよりも、最初にしっかりと理解したほうが結果的に早く進める事ができる。

Deep Code Reading
優秀な人間は他人よりもコードを読んでいる。コードを読む力を身につければより早くより大量にコードを読めるようになる。

どうやってコードを読むのか。今の時代ならAIが文脈まで理解して解説してくれるので、自分で読んでみて分からない部分はすべてAIに質問する。100%理解できる力を身につける。そうすると他のコードを読んでも読めるようになる。

特に今の時代はすごい速度でAIがコードを書いてくれる時代になったが、まだハルシネーションがある。そんなときに自分で読んで悪い部分を見つけて修正する能力が必要。

時代からしてもコードリーディング能力が大切だと考えられる。今後のことを考えてもこの練習をする意味はありそうだ。
