## Pythonでリストを扱うときの注意点

リストが格納された変数を別の変数に代入した場合、コピーが作成されるわけではなく参照の共有が行われる。


## リストの参照の共有

例えば、下記のようなコードがあるとする。
```python
x = [1, 2, 3]
y = x
y.append(4)

print(f"x: {x} id: {id(x)}")
print(f"y: {y} id: {id(y)}")
```

このとき、`x`と`y`は同じリストオブジェクトを参照することになるため、`y`を通じてリストオブジェクトを変更すると、その変更は`x`から参照した場合にも反映される。

```bash
$ python3 main.py
x: [1, 2, 3, 4] id: 140104591788864
y: [1, 2, 3, 4] id: 140104591788864
```


## Shallow copy

元のリストを変更したくない場合は、`copy()`メソッドを利用する。
`copy()`を利用すると、リストの[[Shallow copy\|Shallow copy]]が作成され、その新しいリストへの参照が`y`に代入される。

```python
y = x.copy()
```

すると同じように`append()`を実行した場合でも`x`は変更されず、`y`のみ値が追加される。

```bash
$ python3 main.py
x: [1, 2, 3] id: 139896526244672
y: [1, 2, 3, 4] id: 139896526246528
```
