例えば、下記のようなコードがあるとする。
```
x = [1, 2, 3]
y = x
y.append(4)

print(f"x: {x} id: {id(x)}")
print(f"y: {y} id: {id(y)}")
```

このとき、`x`と`y`は同じメモリ番地を参照することになるため、xもyも同様の値になる。

```
$ python3 main.py
x: [1, 2, 3, 4] id: 140104591788864
y: [1, 2, 3, 4] id: 140104591788864
```

xの値を変更したくない場合は、`copy()`メソッドを利用する。

```
y = x.copy()
```

するとxは変更されず、yのみ値が追加される。

```
$ python3 main.py
x: [1, 2, 3] id: 139896526244672
y: [1, 2, 3, 4] id: 139896526246528
```
