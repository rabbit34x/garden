このVaultはDigital gardenの理念に基づいて作成されています。

## 構造

通常のノートはすべてValutのルートに作成する。
例外として以下のディレクトリを使用する。
- `scratch/`: 日々の雑多なメモ
- `x/`: Vaultの運用に必要なファイル、テンプレート、画像の保管先など

## ノート

ノートをReference, Zettelkasten, Atomicなどの種類に分類することはしない。
必要なことをノートとして書き、必要に応じて`[[Link]]`でほかのノートとつなげる。
ノートのまとまりが必要になった場合は、フォルダを作るのではなくリンクやMOCを利用する。
