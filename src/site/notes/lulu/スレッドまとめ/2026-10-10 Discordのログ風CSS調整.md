# Discordのログ風CSS調整

- DiscordスレッドID：1558386484929634307
- スレッド作成日：2026-10-10 JST
- 記録日：2026-10-10 JST
- 状態：ユーザーが完成と確認し、Closeを宣言。Discordのアーカイブ・ロック操作は行っていない。

## 決定・結果

Windows版DiscordとVencordのQuickCSSを段階的に調整。system24の試用と全体的な端末テーマ化は撤回し、既存テーマを維持する小さな変更へ移行した。最終的に以下をユーザーが受け入れた。

- アバターを残し、ThemeAttributesを用いて投稿者名を等幅に。自分の名前に `$ `、他者に `> ` を付ける。
- 全体背景・左の伊織・右のやよいの画像を保持。背景画像の暗さは黒いオーバーレイで調整する。全体背景を乗算方式で暗くする提案は撤回され、採用しない。
- 伊織をイメージしたピンクのアクセント。HSL 335 / 80% / 72% は提案値であり、公式キャラクターカラーの厳密な再現とはしていない。
- 左ナビゲーション、ヘッダー、チャット履歴、送信エリア、右メンバー一覧を分離。
- チャット履歴には四角い細いグレーの外枠。送信エリアの外側背景は透明。
- メンションと返信操作中の強い全周発光を、角丸なし・幅3pxのピンク左ラインへ変更。強調メッセージの内側余白は上下12px、左右16px。
- 返信先へ伸びる接続線は非表示。返信先の引用表示は残す。
- 入力中表示に専用スペースを常時確保し、表示の有無による縦方向のずれを抑制。ユーザーが実際の入力中表示を確認し、問題なさそうと報告。

## 実施・検証

ユーザーが「問題なし」としたCSS全文を元に、設定値を先頭へ集約し、コメントを短いセクション見出しへ削減。重複した履歴ルールを最終値へ統合した置き換え用CSSを作成・添付した。

静的検証ではtinycss2で21セレクター・67件の有効な宣言を変数展開後に比較し、重要度と値の一致を確認。画像URL3件も完全一致。ブラウザ比較はChromiumがlibnspr4.so不足で起動できず、実施できなかった。実クライアントの見た目・使い心地の確認はユーザーの報告とスクリーンショットに基づく。こちらからユーザーのDiscord設定を直接変更していない。
